# Otvorené problémy (Audit) — TrueHDR Photo Converter

> Tento dokument obsahuje **výhradne otvorené problémy a nedokončenú prácu** so stabilnými ID (`AUD-001`, `AUD-002`, …). *Všetky doterajšie overené zistenia (`AUD-001` až `AUD-010`) boli kompletne opravené, verifikované a presunuté do [docs/CHANGELOG.md](./CHANGELOG.md).*
